# 📘 Assignment: Web Page Design with HTML, CSS, and JavaScript

## 🎯 Objective

Build a simple interactive web page to learn how HTML, CSS, and JavaScript work together to create a styled layout and browser-based interactivity.

## 📝 Tasks

### 🛠️ Create the Web Page Structure

#### Description
Create an `index.html` file with a page title, headings, a short description, and a button that students can click.

#### Requirements
Completed project should:

- Include a page title and a main heading.
- Add at least one paragraph describing the page.
- Include a button labeled `Click me!`.
- Use semantic HTML tags such as `header`, `main`, and `footer`.


### 🛠️ Style the Page with CSS

#### Description
Create a `styles.css` file to add colors, spacing, and layout to the page.

#### Requirements
Completed project should:

- Apply a background color to the page.
- Style the heading and paragraph text with readable colors.
- Style the button with padding, border radius, and hover effect.
- Use at least one class selector.


### 🛠️ Add JavaScript Interactivity

#### Description
Create a `script.js` file to make the button display a message when clicked.

#### Requirements
Completed project should:

- Select the button using JavaScript.
- Add an event listener for the `click` event.
- Display a message on the page when the button is clicked.
- Example message: `Thanks for clicking!`.
